# Kalkan site ve filtreler

- `index.html`, `privacy.html`: destek ve gizlilik sayfaları
- `filters/kalkan.txt`: Kalkan'a özel kurallar (Adblock Plus / AdGuard sözdizimi). Buraya eklenen kural ertesi gün tüm kullanıcılara ulaşır.
- `.github/workflows/filters.yml`: her gün EasyList, EasyPrivacy ve AdGuard (Türkçe, Mobil, Base scriptlet'leri) listelerini indirip `/filters/` altında yayınlar.

Filtre lisansları: EasyList / EasyPrivacy CC BY-SA 3.0 + GPLv3 (https://easylist.to), AdGuard filtreleri GPLv3 (https://github.com/AdguardTeam/AdguardFilters). Çevrilmiş listeler aynı lisanslarla yayınlanır.
